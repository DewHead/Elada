# Product Guidelines - Elada

## Design Philosophy: Clarity over Complexity
The system prioritizes a clean, uncluttered interface to facilitate rapid and accurate task completion. Every element should serve a clear purpose, ensuring the user can generate an invoice with minimal friction.

## Tone and Voice: Professional & Efficient
- **Style:** Concise, direct, and focused on speed and reliability.
- **Feedback:** Provide immediate, subtle validation for data entry. Avoid overly conversational language; prioritize clarity and utility.

## Visual Identity & Polish
- **Minimalist Aesthetic:** Leverage generous white space and refined typography to create a premium, high-end feel.
- **Interactive Elements:** Employ subtle shadows, elegant transitions, and a "glow" effect on active buttons and inputs to provide a sense of depth and tactile quality.
- **Real-time Preview:** If feasible, provide a live visual representation of the invoice fields as the user updates them to instill confidence before generation.

## Functional Patterns & Rules
- **Smart Defaults:** The system MUST automatically calculate and suggest the next logical "INVOICE NO." based on the project's history, while always allowing for a manual override.
- **Auto-Formatting:** Numeric inputs (Totals, Balance Due) should be automatically formatted with the appropriate currency symbols and decimal places as the user types to ensure consistency and professional presentation.
- **Mobile Responsiveness:** All UI components must adapt gracefully to different screen sizes, maintaining usability and visual polish on mobile and tablet devices.

## Accessibility & Usability
- **High Contrast:** Ensure all text and interactive elements meet modern accessibility standards for readability.
- **Logical Flow:** The input sequence should follow the natural order of the invoice template, guiding the user from top to bottom.
